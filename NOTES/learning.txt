========================================
📚 GIT DAY 1
========================================

1. What is Git?

- Git is a Version Control System (VCS).
- It tracks changes in files.
- It helps us save project history.
- It allows us to go back to previous versions.

----------------------------------------

2. What is GitHub?

- GitHub is a cloud platform.
- It stores Git repositories online.
- It is used for backup, collaboration, and portfolio.

----------------------------------------

3. pwd Command

Command:
pwd

Purpose:
Shows the current working directory (current folder path).

----------------------------------------

4. ls Command

Command:
ls

Purpose:
Shows all files and folders inside the current directory.

----------------------------------------

5. cd Command

Command:
cd folder_name

Example:
cd Desktop

Purpose:
Changes the current directory.

----------------------------------------

6. git init

Command:
git init

Purpose:
Converts a normal folder into a Git Repository.

----------------------------------------

7. git status

Command:
git status

Purpose:
Shows:
• Current branch
• Modified files
• Untracked files
• Files ready to commit

----------------------------------------

8. git add .

Command:
git add .

Purpose:
Adds all files to the Staging Area.

----------------------------------------

9. Staging Area

Definition:
A temporary area where files are prepared before committing.

Flow:

Working Folder
      ↓
Staging Area
      ↓
Commit

----------------------------------------

10. git commit

Command:
git commit -m "Message"

Example:
git commit -m "Day 1: First Git Commit"

Purpose:
Creates a save point in project history.

----------------------------------------

11. git log

Command:
git log

Purpose:
Shows commit history.

----------------------------------------

12. Git Configuration

Commands:

git config --global user.name "Prince Chahar"

git config --global user.email "your_email@gmail.com"

Purpose:
Sets your name and email for commits.

----------------------------------------

13. Important Terms

Repository = Project Folder

Commit = Save Point

Branch = Separate line of development

Version Control = Tracking project changes

----------------------------------------

14. Day 1 Commands

pwd

ls

cd Desktop

git init

git status

git add .

git commit -m "Message"

git log

git config --global user.name

git config --global user.email

========================================
🌍 GITHUB DAY 2
========================================

1. What is GitHub?

- GitHub stores Git repositories online.
- It is used for backup.
- It is used for sharing code.
- It helps build a developer portfolio.

----------------------------------------

2. Repository

A Repository is a project stored on GitHub.

Example:
skill-mission-365

----------------------------------------

3. Public Repository

Anyone can view the repository.

----------------------------------------

4. Private Repository

Only selected people can access it.

----------------------------------------

5. Branch Rename

Command:

git branch -M main

Purpose:
Changes branch name from master to main.

----------------------------------------

6. Remote Repository

Command:

git remote add origin https://github.com/username/repository.git

Purpose:
Connects local Git repository to GitHub.

----------------------------------------

7. Check Remote

Command:

git remote -v

Purpose:
Shows connected GitHub repository.

----------------------------------------

8. Push

Command:

git push -u origin main

Purpose:
Uploads local project to GitHub.

----------------------------------------

9. Origin

Origin is the default nickname of the GitHub repository.

----------------------------------------

10. Main

Main is the default branch.

----------------------------------------

11. GitHub Authentication

Purpose:
Verifies your GitHub account before pushing code.

----------------------------------------

12. Upload Process

Working Folder
      ↓
git add .
      ↓
git commit
      ↓
git push
      ↓
GitHub

----------------------------------------

13. Day 2 Commands

git branch -M main

git remote add origin URL

git remote -v

git push -u origin main

========================================
🐍 PYTHON DAY 1
========================================

1. What is Python?
- Python is a high-level, easy-to-learn programming language.
- It is used for AI, Web Development, Automation, Data Analysis, Cyber Security, and more.

2. print() Function
- print() is used to display output on the screen.

Example:
print("Hello, World!")

3. String (str)
- Text written inside double ("") or single ('') quotes is called a String.

Example:
name = "Prince"

4. Comments
- Comments are used to explain the code.
- Python ignores comments during execution.
- Comments start with #.

Example:
# This is a comment

5. Variables
- A variable is a container used to store data.

Example:
name = "Prince"
age = 19

6. Printing Variables

print(name)      → Prints the value stored in the variable.
print("name")    → Prints the word "name".

7. Variable Naming Rules
✔ Can start with letters or underscore (_)
✔ Can contain numbers (not at the beginning)

❌ Invalid:
1name
my-name
my name

8. Basic Data Types

String (str)
Example:
name = "Prince"

Integer (int)
Example:
age = 19

Float (float)
Example:
height = 5.9

Boolean (bool)
Example:
is_student = True

9. type() Function
- type() is used to check the data type of a variable.

Example:
print(type(name))
print(type(age))
