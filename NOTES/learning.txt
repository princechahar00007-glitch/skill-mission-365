📚 GIT DAY 1
========================================

1. What is Git?

- Git is a Version Control System (VCS).
- It tracks changes in files.
- It helps us save project history.
- It allows us to go back to previous versions.

----------------------------------------

2. What is GitHub?

- GitHub is a cloud platform.
- It stores Git repositories online.
- It is used for backup, collaboration, and portfolio.

----------------------------------------

3. pwd Command

Command:
pwd

Purpose:
Shows the current working directory (current folder path).

----------------------------------------

4. ls Command

Command:
ls

Purpose:
Shows all files and folders inside the current directory.

----------------------------------------

5. cd Command

Command:
cd folder_name

Example:
cd Desktop

Purpose:
Changes the current directory.

----------------------------------------

6. git init

Command:
git init

Purpose:
Converts a normal folder into a Git Repository.

----------------------------------------

7. git status

Command:
git status

Purpose:
Shows:
• Current branch
• Modified files
• Untracked files
• Files ready to commit

----------------------------------------

8. git add .

Command:
git add .

Purpose:
Adds all files to the Staging Area.

----------------------------------------

9. Staging Area

Definition:
A temporary area where files are prepared before committing.

Flow:

Working Folder
      ↓
Staging Area
      ↓
Commit

----------------------------------------

10. git commit

Command:
git commit -m "Message"

Example:
git commit -m "Day 1: First Git Commit"

Purpose:
Creates a save point in project history.

----------------------------------------

11. git log

Command:
git log

Purpose:
Shows commit history.

----------------------------------------

12. Git Configuration

Commands:

git config --global user.name "Prince Chahar"

git config --global user.email "your_email@gmail.com"

Purpose:
Sets your name and email for commits.

----------------------------------------

13. Important Terms

Repository = Project Folder

Commit = Save Point

Branch = Separate line of development

Version Control = Tracking project changes

----------------------------------------

1. Comparison Operators

Comparison Operators are used to compare two values.

Operators:

==  -> Equal To
!=  -> Not Equal To
>   -> Greater Than
<   -> Less Than
>=  -> Greater Than or Equal To
<=  -> Less Than or Equal To

Example:

print(10 == 10)
print(10 != 5)
print(20 > 10)
print(5 < 10)

--------------------------------------------------

2. Boolean

Boolean Data Type has only two values.

True
False

Example:

result = (20 > 10)

print(result)
print(type(result))

--------------------------------------------------

3. if Statement

The if statement is used to check a condition.

Syntax:

if condition:
    print("Code")

Example:

age = 18

if age >= 18:
    print("You Can Vote")

--------------------------------------------------

4. if - else Statement

If the condition is True, the if block executes.
Otherwise, the else block executes.

Example:

age = 16

if age >= 18:
    print("Adult")
else:
    print("Minor")

--------------------------------------------------

5. elif Statement

The elif statement is used to check multiple conditions.

Example:

marks = 85

if marks >= 90:
    print("Grade A")
elif marks >= 75:
    print("Grade B")
else:
    print("Fail")

--------------------------------------------------

6. Logical Operators

AND

Both conditions must be True.

Example:

if age >= 18 and has_id:
    print("Entry Allowed")

OR

At least one condition must be True.

Example:

if is_student or age < 18:
    print("Discount Available")

NOT

The NOT operator reverses the result.

Example:

is_logged_in = False

if not is_logged_in:
    print("Please Login")

1. for Loop

The for loop is used to repeat a block of code a fixed number of times.

Syntax:

for variable in range(number):
    print("Code")

Example:

for i in range(5):
    print("Hello")

--------------------------------------------------

2. range()

The range() function generates a sequence of numbers.

Types of range():

1. range(stop)

Example:

range(5)

Output:
0 1 2 3 4

----------------------------

2. range(start, stop)

Example:

for i in range(1, 6):
    print(i)

Output:
1 2 3 4 5

----------------------------

3. range(start, stop, step)

Example:

for i in range(2, 11, 2):
    print(i)

Output:
2 4 6 8 10

--------------------------------------------------

3. while Loop

The while loop runs until the condition becomes False.

Syntax:

while condition:
    print("Code")

Example:

i = 1

while i <= 5:
    print(i)
    i += 1

--------------------------------------------------

4. Infinite Loop

If we forget to update the variable inside a while loop, the loop never stops.

Wrong Example:

i = 1

while i <= 5:
    print(i)

Reason:
i never changes, so the condition always remains True.

--------------------------------------------------

5. break Statement

The break statement immediately stops the loop.

Example:

for i in range(1,11):

    if i == 6:
        break

    print(i)

Output:
1
2
3
4
5

--------------------------------------------------

6. continue Statement

The continue statement skips the current iteration and moves to the next one.

Example:

for i in range(1,6):

    if i == 3:
        continue

    print(i)

Output:
1
2
4
5

--------------------------------------------------

7. Nested Loop

A Nested Loop means one loop inside another loop.

Example:

for i in range(3):

    for j in range(3):
        print(i, j)

--------------------------------------------------

8. Star Pattern

Example:

for i in range(3):

    for j in range(5):
        print("*", end="")

    print()

Output:

*****
*****
*****

--------------------------------------------------

9. Table Generator

Using a for loop, we can create a multiplication table.

Example:

for i in range(1,11):
    print(num, "x", i, "=", num*i)

--------------------------------------------------

1. List

A List is used to store multiple values in a single variable.

Syntax:

list_name = [item1, item2, item3]

Example:

fruits = ["Apple", "Banana", "Mango"]

print(fruits)

--------------------------------------------------

2. List Rules

• List is written inside square brackets [ ]
• Items are separated by commas
• A list can store different data types
• Lists are ordered and mutable (can be changed)

Example:

data = ["Prince", 20, True, 89.5]

--------------------------------------------------

3. Indexing

Every item in a list has an index number.

Index starts from 0.

Example:

fruits = ["Apple", "Banana", "Mango"]

print(fruits[0])

Output:

Apple

--------------------------------------------------

4. Negative Indexing

Negative indexing starts from the end.

-1 means last item.

Example:

fruits = ["Apple", "Banana", "Mango"]

print(fruits[-1])

Output:

Mango

--------------------------------------------------

5. Slicing

Slicing is used to get multiple items from a list.

Syntax:

list[start:stop]

Remember:

✓ Start Index Included
✓ Stop Index Excluded

Example:

fruits = ["Apple", "Banana", "Mango", "Orange"]

print(fruits[1:3])

Output:

['Banana', 'Mango']

--------------------------------------------------

6. append()

append() adds a new item at the end of the list.

Example:

fruits = ["Apple", "Banana"]

fruits.append("Mango")

print(fruits)

Output:

['Apple', 'Banana', 'Mango']

--------------------------------------------------

7. insert()

insert() adds an item at a specific index.

Syntax:

list.insert(index, value)

Example:

numbers = [10, 20, 40]

numbers.insert(2, 30)

print(numbers)

Output:

[10, 20, 30, 40]

--------------------------------------------------

8. remove()

remove() deletes an item by its value.

Example:

fruits = ["Apple", "Banana", "Mango"]

fruits.remove("Banana")

print(fruits)

Output:

['Apple', 'Mango']

--------------------------------------------------

9. pop()

pop() removes an item using its index.

Example:

fruits = ["Apple", "Banana", "Mango"]

fruits.pop(1)

print(fruits)

Output:

['Apple', 'Mango']

If no index is given:

fruits.pop()

It removes the last item.

1. Set

A Set is used to store multiple values in a single variable.

Set is created using curly brackets { }.

Example:

fruits = {"Apple", "Banana", "Mango"}

--------------------------------------------------

2. Set Rules

• Set uses curly brackets { }
• Duplicate values are not allowed
• Set is unordered
• Set does not support indexing

Example:

numbers = {10, 20, 10, 30}

Output:

{10, 20, 30}

--------------------------------------------------

3. add()

Adds a new item to the set.

Example:

fruits.add("Orange")

--------------------------------------------------

4. remove()

Removes an item from the set.

If the item is not found,
Python gives an error.

Example:

fruits.remove("Apple")

--------------------------------------------------

5. discard()

Removes an item from the set.

If the item is not found,
No error is generated.

Example:

fruits.discard("Apple")

--------------------------------------------------

6. clear()

Removes all items from the set.

Example:

fruits.clear()

--------------------------------------------------

7. Function

A Function is a reusable block of code.

It helps avoid writing the same code again and again.

Syntax:

def function_name():
    statements

function_name()

--------------------------------------------------

8. Function Advantages

• Code Reuse
• Less Repetition
• Easy to Read
• Easy to Maintain

--------------------------------------------------

9. Parameters

Parameters are used to send data into a function.

Example:

def greet(name):
    print("Hello", name)

greet("Prince")

--------------------------------------------------

10. Multiple Parameters

A function can receive more than one parameter.

Example:

def student(name, course):
    print(name, course)

--------------------------------------------------

11. Return Statement

The return keyword sends a value back from a function.

Example:

def add(a, b):
    return a + b

answer = add(10, 20)

print(answer)

--------------------------------------------------

12. Difference

print()

• Displays output only.

return

• Sends value back.
• Can be stored in a variable.
• Can be reused later.

--------------------------------------------------
